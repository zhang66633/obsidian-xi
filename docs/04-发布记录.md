## 0.5.0 发布 checklist

- [x] README / CHANGELOG / docs 更新（功能与实现一致）
- [x] 版本三处同步（`npm version 0.5.0 --no-git-tag-version`）
- [x] 本地验证：`npm run check`（lint + 141 tests + build）
- [x] 真机：装入本地库、冷启动、面板/设置页可用
- [ ] 提交 master 并推送
- [ ] `git tag 0.5.0 && git push origin 0.5.0`
- [ ] GitHub Actions 生成 draft release + attestation
- [ ] 补 release notes，Publish
- [ ] 等社区目录重扫（HEAD manifest 已是 0.5.0）
- [ ] 本地 Obsidian 更新到 0.5.0 并确认版本号

## 发布命令（一次性）

```bash
npm version 0.5.0 --no-git-tag-version
npm run check
git add -A
git commit -F TEMP/commit-0.5.0.txt
git push origin master
git tag -a 0.5.0 -m "0.5.0"
git push origin 0.5.0
```

## 历史备注

- 2026-10-06 提交走的是 community.obsidian.md 网页目录（无 PR 流程）；obsidian-releases 的
  PR API 对该仓库返回 404（见 02-踩坑 P9/P10）。
- 目录条目由网页端审核后写入 `community-plugins.json`；新版本不需要重新提交，
  只要 HEAD manifest 版本 + 对应 tag 的 release 存在，Obsidian 就会拉到新版本。
